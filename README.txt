# Arif & Muskan — 3D Wedding Invitation

A responsive 7-page 3D wedding invitation website.

## Files
- index.html — all invitation pages/content
- style.css — 3D page transitions, gold/teal wedding theme, responsive layout
- script.js — navigation, swipe, keyboard, click and replay controls
- assets/wedding-bg.jpg — uploaded invitation artwork used as the visual background

## Run
1. Keep the folder structure unchanged.
2. Open `index.html` in Chrome/Edge.
3. For best mobile behavior, use a local server from this folder:
   - VS Code Live Server, or
   - `python -m http.server 8000`
4. Open `http://localhost:8000`

## Controls
- Swipe left/right on mobile
- Click the left/right side of the card
- Arrow buttons
- Keyboard: Left / Right / Space
- Replay on the final page

All event text is in `index.html`, so it can be edited directly.
